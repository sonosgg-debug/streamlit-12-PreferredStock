# 한국증시 우선주 목록 및 투자 지표 비교 대시보드

한국 증시(코스피, 코스닥)에 상장된 모든 우선주와 해당 보통주의 투자 지표를 비교 분석할 수 있는 대시보드 웹 애플리케이션입니다.

## 📌 주요 특징 및 기능

1. **신뢰할 수 있는 공식 데이터 소스**:
   - KRX 정보데이터시스템(pykrx)과 직접 연동하여 전일 종가, 시가총액, EPS, DPS, 배당수익률을 공식 수집합니다.
   - 당일 데이터 로컬 캐싱을 적용하여 첫 로드 이후에는 즉각적(0.1초)으로 화면이 렌더링됩니다.

2. **13개 필수 투자 지표 비교 테이블**:
   - **시장**: 코스피 / 코스닥
   - **보통주명** / **우선주명**
   - **시가총액(보통주)** (억원 단위)
   - **배당성향 (%)**: `(보통주 DPS / 보통주 EPS) * 100`
   - **보통주가** / **우선주가** (원)
   - **괴리율 (%)**: `(보통주가 - 우선주가) / 보통주가 * 100` (보통주 대비 할인율)
   - **보통주 배당금** / **우선주 배당금** (원)
   - **보통주 배당수익률(A)** / **우선주 배당수익률(B)** (%)
   - **배당수익률 비율(B/A)** (배율)

3. **인터랙티브 기능**:
   - **항목별 정렬**: 각 컬럼 헤더 클릭 시 오름차순/내림차순 즉시 정렬
   - **엑셀 다운로드**: 서식(숫자 천단위 콤마, 비율, 자동 열 너비)이 지정된 `.xlsx` 파일 다운로드
   - **스마트 필터**: 시장 선택(전체/코스피/코스닥), 종목 검색, 최소 배당수익률, 최소 괴리율 필터링

4. **종목별 상세 시각화 차트 (Plotly)**:
   - 보통주 vs 우선주 주가 추이 (실제 주가 및 기준일=100 상대 수익률 비교)
   - 역사적 괴리율(%) 추이 및 기간 평균선 밴드 차트
   - 보통주 vs 우선주 주당배당금(원) 및 배당수익률(%) 바/포인트 비교 차트
   - 투자 매력도 및 핵심 체크포인트 (괴리율 진단, 배당 프리미엄 분석)

5. **디자인 테마**:
   - `00 Bookmarks` 앱의 다크 테마(Slate-900 `#0f172a`, 패널 `#1e293b`, 보더 `#334155`) 및 타이틀 색상(`color: #8AB4F8 !important;`)을 완벽하게 계승

## 🚀 실행 방법

### 방법 1: 배치 파일 실행
`run_app.bat` 파일을 더블 클릭하여 실행합니다.

### 방법 2: 명령 프롬프트 실행
```bash
python -m streamlit run app.py
```
브라우저가 자동으로 열리며 대시보드가 표시됩니다.
